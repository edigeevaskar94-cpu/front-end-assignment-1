# YachtRent Astana

YachtRent Astana is a responsive multi-page website created as a team front-end project.  
The website presents a yacht rental service where users can explore available yachts, learn about the company and its services, send a booking request, and find contact information.

## Live Website

https://edigeevaskar94-cpu.github.io/front-end-assignment-1/

## Pages

- `index.html` — Home page
- `cars.html` — Yacht catalog
- `about.html` — About the company
- `services.html` — Services
- `booking.html` — Booking page
- `contacts.html` — Contact information

## Main Features

- Responsive design for desktop, tablet, and mobile devices
- Responsive navigation menu
- Yacht catalog with cards and images
- Booking interface
- Services and company information
- Contact page
- Consistent design and navigation across all pages

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Flexbox
- CSS Media Queries
- GitHub Pages
